# Spyder-Ambient-Brightness-Controller
-A Vibe-coded Tool that uses any Spyder Colorimeter with an ambient light sensor to dynamically control monitor brightness with the Hardware DDC/CI Protocol

-Needs ArgyllCMS to access Spyder hardware sensors: https://argyllcms.com/downloadwin.html
